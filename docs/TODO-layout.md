# Melhorias de layout (pendentes)

Levantadas na revisão de UX (Pixel). Ordem = prioridade.

## Maior impacto
1. **Resumo no topo do relatório**: faixa com 4 áreas (Segurança, Governança, Armazenamento, Licenças), semáforo, nota e achado principal, cada uma levando à aba certa. Os 6 KPIs e a lista de achados viram detalhe.
2. **Painel útil**: coletas em andamento com barra de progresso (lotes/sites), últimas concluídas com 2–3 números-chave (TB, achados críticos, economia) e "pede atenção" com o botão da ação. Remover o card que repete o KPI.
3. **Cliente novo como passo a passo**: trocar "Prontidão" por 4 etapas numeradas com botão (enviar guia → configurar conexão → testar → primeira coleta).

## Médio impacto
4. Cabeçalho do relatório compacto (execução + comparação numa linha) e abas fixas ao rolar.
5. Números nas abas do relatório sem significado claro ("Exchange 90"): remover ou explicitar ("90 caixas").
6. Barra dos KPIs: cinza para neutro; cores só para estado (roxo fica para ações).

## Polimento
7. Telas vazias com o botão do próximo passo (Execuções, Higienização).
8. Abas do relatório no celular numa linha com rolagem lateral.
9. Duplicados: trocar o link "Baixar CSV" de cada linha por ícone discreto.
10. "Evolução entre coletas": reduzir a altura dos minigráficos.

- Logo usa cores fora do Brandbook 2026 (#EA5A1C, #662483, #95C11F). Trocar só com o SVG oficial do Marketing (vale também para o Target360).
